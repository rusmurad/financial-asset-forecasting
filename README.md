# Прогнозирование стоимости финансовых активов

Проект посвящён прогнозированию стоимости финансовых активов на основе исторических данных.

## Цель проекта

Разработать и сравнить методы прогнозирования стоимости финансовых активов, работая с временными рядами.

## План работ

1. Провести разведочный анализ (EDA) данных американского рынка акций: изучить данные и связи между признаками, построить визуализации и сформулировать выводы.
2. Выбрать метрику, обучить первые ML-модели и попробовать улучшить их обработкой данных и подбором гиперпараметров.
3. Реализовать ML-сервис на FastAPI для получения прогнозов.
4. Улучшить модели с помощью более сложных подходов, работы с признаками и данными; применить нейронные сети и сравнить результаты с ML-моделями.
5. Настроить MLflow и воспроизводимость экспериментов, сохранить и залогировать лучшую модель и её артефакты, проанализировать ошибки и устойчивость модели.
6. Подготовить промежуточную и итоговую презентации проекта.
